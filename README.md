## 🚀 Featured: robo-cortex

Most "agent memory" tools are a vector DB with a nice API — they'll happily hand your agent a lesson that stopped being true three commits ago. robo-cortex is built on a different premise: **a memory is only as trustworthy as the code it points at.**

- 🔗 **Git-anchored** — every memory is bound to a git blob hash; edit the code, the memory is flagged for review automatically
- 🧾 **Evidence-based** — memories carry re-runnable evidence and explicit confidence, not free-floating notes
- 🪶 **Zero-infrastructure** — pure stdlib + local SQLite, scoped to your repo. No embeddings, no vector DB, no cloud, no daemon
- 🔌 **MCP-native** — 8 tools; works with Claude Code, Cursor, and any MCP client

```bash
pip install robo-cortex[mcp]
```
